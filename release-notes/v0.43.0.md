## Recipes tab for everyone

* The **Recipes** tab is now visible to every user, not only administrators. Everyone can rate, remove ratings and write notes, so the whole household feeds the suggestions.
* Deleting a recipe stays with administrators (the delete button is hidden for other users, and the `delete_recipe` action is now admin only). Taste profile and settings stay admin only as before.
* `settings: false` in the card config now hides only the Settings tab, as documented.
