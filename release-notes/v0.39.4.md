## Fair choice between AI providers

* The setup no longer preselects Claude when creating the search agent. It only suggests the provider of the main AI you already picked, otherwise "No".
* New search agents are set up the same way for every provider: a current low-cost model (Gemini `gemini-3.8-flash`, Claude `claude-haiku-5-5`, ChatGPT `gpt-6.1-terra`), web search on, 16000 maximum tokens, no access to your home. You can change the model in the agent. Existing agents stay as they are.
* Setup texts and README describe all providers neutrally; the only tip left is that Gemini can be used for free.
