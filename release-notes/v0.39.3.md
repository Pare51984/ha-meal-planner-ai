## Fixes

* The search agent the integration creates now carries the provider in its name, e.g. "Essensplaner Rezeptsuche (Claude)", so several agents can be told apart. Existing agents keep their name and are still recognised.
* New Gemini search agents use `gemini-3.8-flash` (searches fine on the free tier in our test). Existing agents keep their model.
* The "Remembered" card no longer asks the integration before it has started (no more "not set up yet" errors in the log after a restart), and for non-admin users it no longer redraws on every state change in the house.
