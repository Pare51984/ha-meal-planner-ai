## Fixes from a code review

**Shopping list**
* Removing a dish no longer can loop when its name appears inside another note (e.g. "(vegan)"), and dish names containing " + " are tagged safely.
* Quick taps no longer write ingredients twice: list updates now run one after another.
* Replacing or clearing a week, or finishing the selection after removing a shopping trip in the settings, now also takes the dropped dishes' ingredients off the list.
* "2 Zwiebel(n) (fein gewürfelt)" is now read as "Zwiebeln" with the note "fein gewürfelt".
* AI shopping names are recalculated when staples, catalog or region change.

**Planning**
* Swap no longer fails because of weekly rules in the running week and never touches other dishes.
* Wishes are recognised as done when the dish only partly matches the wish text (e.g. "something with pumpkin"), and are no longer blocked by dishes that were rejected or cooked recently.
* The same Thermomix recipe can no longer end up twice ("(TM)" suffix).
* A carried-over dish that gets cooked before the selection deadline does not reappear in the new week.
* Timed shopping trips are never released before the selection deadline.
* Rating a dish a day after cooking keeps the original cooking date.
* Cookidoo: alternative links must point to Cookidoo.

**Robustness**
* AI answers with several code blocks or broken result lists are handled.
* The own wish list and built-in shopping list are no longer offered as a shopping list during setup.
* "low_calorie" removed from the assess_recipes action (it was rejected anyway).
