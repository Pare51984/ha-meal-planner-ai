## Fixes from the live test with Claude and ChatGPT

**Recipe search**
* A search result now has to be the same dish: the main ingredient must match ("pumpkin curry" no longer becomes "chicken curry", "pumpkin pan with feta" no longer a feta dip).
* A dish meant to be vegetarian is no longer replaced by a recipe with meat or fish.
* Meat in the ingredients or the title now beats a wrong "vegetarian" label on the recipe page (e.g. a turkey gyros was shown as meat-free).
* The search budget grows with the number of dishes per week, so a run still fills the week when the AI delivers no links of its own.
* kochbar.de is left out of the integration's own search (its search page answers 404); links to kochbar.de from the AI still work.

**AI answers**
* Errors from a conversation agent now show the real message instead of only "unknown".
* An empty AI answer is reported clearly, with a hint to raise *maximum tokens* in the AI integration (Claude with thinking needs more than the default 3000).
* Dishes that were rejected in a run are named first in the next request, so the AI stops proposing them again. Titles like "X-Alternative: Y" are rejected.

**Other**
* Pressing a button while suggestions are being created no longer writes an error to the log.
