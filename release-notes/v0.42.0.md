## Fixes from the HACS review

* **Shopping list never deletes your own items.** Before, if you had put e.g. "Milch" on the list yourself and a planned dish also needed milk, deselecting or dropping that dish could remove your "Milch". Now the integration remembers which items it created itself and only deletes those. On items that were already on the list it only adds and later removes its own part of the description; your original description is restored.
* **No more stall on the first recipe fetch.** The recipe parser (recipe-scrapers) is now loaded together with the integration instead of on the first fetch, which briefly blocked Home Assistant, noticeably on a Raspberry Pi.
* **Settings actions are admin only.** `set_profile` and `external_setup` change the integration's configuration and can now only be called by administrators (the card already hid them from other users). Switching to the external AI through the AI tool `meal_planner_setup` with `activate: true` also requires an administrator.

## Note

Items the integration added before this update are not known as its own yet. When such a dish is dropped, its part is removed from the description but the item stays on the list; remove it by hand if you don't need it.
